# Pathway-Analysis
Scripts can be used to add gene–protein–reaction associations from genome scale model iML1515 and pathways from Ecocyc to Hit List from FI-MS screen.
Dteiled description can be found in STAR procol (cite protocol here).

# step by step instructions
Download Pathway-Analysis from GutHub.
Unzip folder.
Open folder in MATLAB. Ensure that all folders and subfolder are added to the MATLAB path.
Run PathwayAnalysis.m
Reactants and Pathways are added to the hitList and are saved with "hitList_Pathways.xlsx"
